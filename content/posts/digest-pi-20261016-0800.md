## 版本概览

本期包含 Pi 1.3.0 版本更新，整体围绕缓存优化、提供商协议调整、会话分享配置以及各种稳定性与环境兼容性修复展开。

## 逐版本解读

### Pi 1.3.0（2026-10-15）

**新增** —— 支持通过 sessionShareDestination 选择 /share 上传位置（自动、gist 或 radius），详情见 Sessions and context 与 Export or share a session（相关链接：https://pi.dev/docs/latest/settings#sessions-and-context https://pi.dev/docs/latest/sessions#export-or-share-a-session）。OpenAI GPT-6 更改思考级别时保持提示词缓存。Kimi Code 切换至 Chat Completions 协议，中途添加工具不再使提示词缓存失效，models.json 基础 URL 覆盖必须包含 /v1，详情见 Providers（相关链接：https://pi.dev/docs/latest/providers）。干净的模型切换，丢弃来自前一个模型的思考过程，而不是作为文本显示给新模型。恢复的会话保留其激活的工具，--tools +name/-name 会在其之上应用，详情见 Tools（相关链接：https://pi.dev/docs/latest/settings#tools）。在 OpenAI GPT-6 模型（API 密钥）上中途更改思考级别现在可以保持提示词缓存（#10853）（相关链接：https://github.com/earendil-works/pi/issues/10853）。添加了 sessionShareDestination 设置，用于为 /share 选择自动、GitHub gist 或 Radius 上传（#10870，由 @vegarsti 贡献）（相关链接：https://github.com/earendil-works/pi/issues/10870 https://github.com/vegarsti）。

**改动** —— 将 kimi-coding 提供商更改为使用 OpenAI Chat Completions（https://api.kimi.com/coding/v1），即官方 Kimi Code 客户端使用的协议。K3、K3-256K 和 Kimi For Coding 现在接受中途添加的工具而不会使提示词缓存失效。models.json 对 kimi-coding 基础 URL 的覆盖现在必须包含 /v1（#10720）（相关链接：https://github.com/earendil-works/pi/issues/10720）。更改模型切换，丢弃由不同模型产生的前期助手消息中的思考块，而不是将其发送为纯文本（#10995）（相关链接：https://github.com/earendil-works/pi/issues/10995）。

**修复** —— 将 Pi 内部依赖项固定到确切的发布版本，以防止全新安装混合不兼容的包（#10865）（相关链接：https://github.com/earendil-works/pi/issues/10865）。修复了恢复的会话丢弃在会话期间激活的工具的问题（#10785）（相关链接：https://github.com/earendil-works/pi/issues/10785）。修复了停止 codemode 脚本或达到其截止时间时等待 Bun 上不可中断的内置程序返回的问题（#10748）（相关链接：https://github.com/earendil-works/pi/issues/10748）。修复了重复的 codemode 超时或中止累积存活工作线程的问题（#10748）（相关链接：https://github.com/earendil-works/pi/issues/10748）。修复了当多个提供商匹配时 --model 按目录顺序选择提供商的问题（#10160）（相关链接：https://github.com/earendil-works/pi/issues/10160）。修复了 TUI、会话树、HTML 导出和示例中数字字符串或 null 参数的读取行范围标签（#9887）（相关链接：https://github.com/earendil-works/pi/issues/9887）。修复了当提供商切换 API 时 Nix flake 构建失败的问题（#10985）（相关链接：https://github.com/earendil-works/pi/issues/10985）。修复了 Nix 软件包将 Node.js 置于 PATH 首位的问题（相关链接：https://github.com/earendil-works/pi/issues/10519）。

## 升级建议

建议升级至 Pi 1.3.0 以获得更好的 GPT-6 缓存与 Kimi Code 体验。升级前请留意 kimi-coding 提供商的 URL 覆盖需要包含 /v1 后缀。
