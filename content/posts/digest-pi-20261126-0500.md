## 版本概览

本期包含 Pi 1.6.1 版本的更新，整体聚焦于决策模型的集成、配置项的精细化拆分、扩展程序能力的增强以及核心稳定性的修复。

## 逐版本解读

### Pi v1.6.1（2026-11-25）

**新增** —— 引入了 codemode 中的 GitHub Copilot gpt-6-luna-decisions 和 Radius 决策模型调用支持，结果包含提供商的 responseId（详见 https://docs.pi.dev/latest/codemode#classify）；在 /settings 的 Notices 下为缓存未命中、缓存预热、压缩成本和推理丢弃分别提供了独立设置（详见 https://docs.pi.dev/latest/settings#model-and-thinking）；扩展程序 UI 方法接受 blockedKind 参数以支持程序状态展示（详见 https://docs.pi.dev/latest/extensions#program-status-kind）。新增 compat.supportsStrictMode 供 google-generative-ai 与 google-vertex 使用（#12321 https://github.com/earendil-works/pi/issues/12321）；新增 bash 工具的结构化输出和 details 字段中的 full_output_error / fullOutputError（#10585 https://github.com/earendil-works/pi/issues/10585）；在 codemode models.classify() 中新增 gpt-6-luna-decisions 模型（#12395 https://github.com/earendil-works/pi/issues/12395）与 responseId 返回值。

**改动** —— 将默认的 Mistral 模型从 devstral-medium-latest 更改为 mistral-medium-latest；调整了 after_provider_response 触发时机，使其对 HTTP 错误响应（4xx/5xx）及重试请求同样生效（#12376 https://github.com/earendil-works/pi/issues/12376）；优化首次安装设置，仅显示彩色 pi logo 和分析选项。

**修复** —— 修复了 Gemini 4 Hydrogen 和 Neon 模型的 xhigh 思考级别映射失败问题（#12184 https://github.com/earendil-works/pi/issues/12184）；修复了压缩后条目过多的会话加载时发生栈溢出的问题（#12154 https://github.com/earendil-works/pi/issues/12154）。

**破坏性变更** —— 用四个独立的 notices.* 设置替换了全局的 showCacheMissNotices 设置，并移除了 SettingsManager.getShowCacheMissNotices() 与 setShowCacheMissNotices() 方法。

## 升级建议

建议升级至最新版本以体验全新的决策模型与更完善的错误处理。升级前请注意通知设置项的破坏性变更，相关自定义配置可能需要适配新的 API。
