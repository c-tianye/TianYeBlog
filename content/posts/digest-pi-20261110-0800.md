## 版本概览

Pi 1.5.1 是一次重要更新，包含了多项核心功能升级与问题修复。本次更新重点引入了 Shell 端独立登录登出、Anthropic 消息线程上下文优化、空闲 Prompt 缓存预热以及更丰富的 Mermaid 图表渲染支持。

## 逐版本解读

### Pi 1.5.1（2026-11-09）

**新增**

- Shell 登录与登出 —— 无需启动会话即可通过 `pi auth login <provider>` 与 `pi auth logout <provider>` 进行凭据管理，支持 API Key 与无浏览器登录。参阅 [Credential commands](https://pi.dev/docs/latest/cli#credential-commands)。

- 空闲 Prompt 缓存预热 —— 符合条件的缓存可在两次运行之间保持最多 30 分钟预热状态。参阅 [cacheWarming](https://pi.dev/docs/latest/settings#model-and-thinking)。

- Anthropic 消息线程支持 —— 单次请求仅发送新增消息，服务端保持对话上下文；当早期上下文变更时自动降级回完整请求。参阅 [Anthropic compatibility](https://pi.dev/docs/latest/models-configuration#anthropic-messages) 及 [PR #11545](https://github.com/earendil-works/pi/pull/11545)。

- 更丰富的 Mermaid 图表 —— 支持饼图、自定义样式以及分支与压缩摘要中的图表展示。参阅 [Display settings](https://pi.dev/docs/latest/settings#terminal-and-display) 与 [Markdown transformers](https://pi.dev/docs/latest/extensions#piregistermarkdowntransformertransformer-options)。

- GitHub Copilot 分类器 —— 支持通过 `codemode models.classify()` 调用 `Microsoft-Decision-1` 模型。参阅 [Use classifier models](https://pi.dev/docs/latest/models#use-classifier-models)。

- 扩展包更新摘要 —— `pi update --extensions` 会展示具体 npm 版本或 Git commit 的变动信息。参阅 [Update Pi or packages](https://pi.dev/docs/latest/cli#update-pi-or-packages) 及 [PR #11707](https://github.com/earendil-works/pi/pull/11707)、[PR #11711](https://github.com/earendil-works/pi/pull/11711)。

- Markdown 转换器增强 —— `pi.registerMarkdownTransformer()` 增加 `{ messageTypes }` 参数以指定目标渲染区域。

**改动**

- 更新逻辑改动 —— `pi update` 现在会细化区分未变更、已跳过与带警告的更新项。

- 上下文处理机制优化 —— Grep 工具改由 ripgrep 直接获取上下文行，减少冗余文件读取。
