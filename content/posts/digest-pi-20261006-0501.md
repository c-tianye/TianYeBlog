## 版本概览

本期更新包含 Pi 1.0.4 版本。本次更新重点增强了命令行中的工具过滤与 MCP 控制，改善了 Codemode 中的图片支持，并修复了大量的系统提示词、网络重试及 MCP 会话问题。

## 逐版本解读

### Pi 1.0.4（2026-10-05）

**新增** ——

- 支持在 `--tools` 与 `--exclude-tools` 中使用 `*` 通配符模式（例如 `--tools read,codemode,'mcp__radius__*'`）；新增 `--no-mcp` 参数以在单次运行中禁用内置 MCP 支持。现在 `--tools` 默认会保留 MCP 工具，除非条目以 `mcp__` 开头（参见 [Tools](https://pi.dev/docs/latest/cli#tools) 及 [MCP tools](https://pi.dev/docs/latest/cli#mcp-tools)）。
- Codemode 支持图片持久化：在图片文件上调用 `tools.read()` 会返回可被 `image()` 展示的图片块（参见 [Call tools](https://pi.dev/docs/latest/codemode#call-tools)）。

**修复** ——

- 修复了围栏代码块中多行字符串和注释在第一行后失去语法高亮颜色的问题（[#10143](https://github.com/earendil-works/pi/issues/10143)）。
- 修复了 Codemode 脚本无法从 `read` 接收图片的问题（[#10251](https://github.com/earendil-works/pi/issues/10251)）。
- 修复了在支持 OpenID Connect 客户端注册的服务器（如 `mcp.modem.dev`）上 MCP OAuth 登录失败并提示 `invalid_redirect_uri` 的问题；Pi 现在注册为原生客户端（[#10493](https://github.com/earendil-works/pi/issues/10493)）。
- 修复了 `--tools` 移除 MCP 工具导致 `pi --tools codemode` 没有任何 MCP 服务器的问题；现在除非条目以 `mcp__` 开头，否则会保留 MCP 工具。
- 修复了 MCP 会话关闭在服务器仍在连接时就返回，导致其传输层保持打开直至服务器响应或超时的问题（[#10249](https://github.com/earendil-works/pi/issues/10249)）。
- 修复了系统提示规则和 skills 提示指出已被 `prepareLoadout` 隐藏的工具名称的问题（[#10343](https://github.com/earendil-works/pi/issues/10343)）。
- 修复了 Bedrock 请求在 HTTP/2 连接停滞并报 "The pending stream has been canceled" 错误后未能自动重试的问题（[#10379](https://github.com/earendil-works/pi/issues/10379)）。
- 修复了修改内置对象（例如 `Array.prototype.toJSON = ...`）的 Codemode 脚本引发崩溃并导致工具调用未完成的问题；内置对象现在会在脚本运行前被冻结（[#10444](https://github.com/earendil-works/pi/issues/10444)）。

## 升级建议

建议所有使用 Codemode 与 MCP 功能的用户升级到 1.0.4 版本，以获得更稳定的命令行工具过滤与错误修复体验。
