## 版本概览

本期包含 Pi 1.1.0 版本的重大更新，整体主题聚焦于智能模型扩展、终端交互体验提升以及工具链的精细化配置。

## 逐版本解读

### Pi 1.1.0（2026-10-07）

**新增** —— 引入了通过 OSC 7501 的程序状态报告，支持终端和代理仪表板查看运行状态（相关链接：https://pi.dev/docs/latest/terminal-setup#program-status）。新增 Claude Haiku 5.5（anthropic/claude-haiku-5-5），支持自适应思考与 Bedrock 提示词缓存。支持通过 +name/-name 调整默认工具选择（相关链接：https://pi.dev/docs/latest/cli#tools）。通过 Decisions API 引入 OpenAI 的 GPT-6 Luna 分类器，codemode 的 models.classify() 现支持图像输入（相关链接：https://pi.dev/docs/latest/models#use-classifier-models）。原生支持由 llama.cpp 0.6.0 或更高版本驱动的决策模型（相关链接：https://pi.dev/docs/latest/llama-cpp#classification）。在事件与会话中增加了 aborted 状态，并记录了 durationMs 耗时（相关链接：https://github.com/earendil-works/pi/issues/10549，https://github.com/earendil-works/pi/issues/10607）。

**改动** —— 调整了 outputPad 的应用范围，现同样适用于 ! 命令输出、工具输出和摘要块（相关链接：https://github.com/earendil-works/pi/issues/9946，https://github.com/earendil-works/pi/pull/10557）。修改了 pi mcp login --timeout 的超时逻辑，将其限制为涵盖整个登录过程（相关链接：https://github.com/earendil-works/pi/issues/10565）。

**修复** —— 修复了 Bash 和 PowerShell 结果在重新加载会话后丢失耗时记录的问题（相关链接：https://github.com/earendil-works/pi/issues/10549）。修复了托管安装会话中保留所有旧版本的问题，现在更新时仅保留新版本及上一个版本（相关链接：https://github.com/earendil-works/pi/issues/10392，https://github.com/earendil-works/pi/pull/10511）。

## 升级建议

本次更新带来了更强大的模型集成与终端监控能力，强烈建议所有用户升级至 v1.1.0 以获得更稳定的运行表现和新功能支持。
