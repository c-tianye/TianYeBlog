## 论文精选

### [Pixel: A Co-Designed Full-Stack Robot System for Learning General-Purpose Mobile Manipulation](https://arxiv.org/abs/2611.03648v1)

一篇新论文提出了全栈协同设计的通用移动操作机器人系统 Pixel，通过整合硬件设计、数据采集、全身控制与策略学习，解决了软硬件解耦导致的性能不匹配问题。

### [Pixel-UMI: Learning Environment-Aware Whole-Body Manipulation from Sensorized Human Demonstrations](https://arxiv.org/abs/2611.03647v1)

一篇新论文提出了 Pixel-UMI 框架，通过结合三维场景几何重建与传感器采集的人类示范轨迹，有效解决了人类与机器人躯体差异带来的姿态重映射与环境感知全身操控难题。

### [Pretraining Data Scale Reverses the Muon-AdamW Fine-Tuning Gap](https://arxiv.org/abs/2611.03633v1)

一篇新论文探讨了新型优化器 Muon 与经典 AdamW 在微调阶段的表现，研究发现在预训练数据量超越一定阈值后，AdamW 的 downstream 微调效果会反超 Muon。

### [WebHarbor: Docking Real Websites for Evolving GUI Agent Environments](https://arxiv.org/abs/2611.03634v1)

一篇新论文构建了包含 153 个 Docker 化真实网站的环境集 WebHarbor，为 GUI Web Agent 的训练与评估提供了高度逼真、稳定且支持交互的基准环境。

### [Strategist: Evolving Reasoning with Agents](https://arxiv.org/abs/2611.03618v1)

一篇新论文提出了 Meta-Agent 框架 Strategist，将推理流程代码化为可执行蓝图，实现了在不同任务间自动化演进与迁移推理策略的能力。
