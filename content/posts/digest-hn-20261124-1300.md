## 重点

### [Stalwart is now a drop-in replacement for Microsoft Exchange](https://stalw.art/blog/microsoft-exchange-replacement/)

Stalwart 是一款功能完备的开源邮件服务器，本次更新进一步支持了 Exchange 协议特性，使其能够直接无缝替代企业级的 Microsoft Exchange 部署。对于想要摆脱商业邮件系统依赖的技术团队而言，这是一个极具潜力的自托管替代方案。

### [GPUI is getting its own repository](https://github.com/zed-industries/gpui)

GPUI 是 Zed 高性能文本编辑器底层依赖的 Rust 向量图形与 UI 框架，如今从 Zed 主仓库中独立出来拥有了独立的开源仓库。这将极大地方便更多 Rust 开发者直接使用该框架来构建高性能的桌面原生应用。
