## 概览

本期 AI 动态主要涵盖企业级服务拓展与技术创新。OpenAI 进一步简化了企业采购流程并展示了其 API 在工业图纸检索中的实际应用；NVIDIA 与 Amazon 则分别在 Hugging Face 博客上分享了针对日本金融背景的合成数据集及大模型混合专家结构剪枝的新方法。

## 官方动态

### [ChatGPT Enterprise now available in AWS Marketplace](https://openai.com/index/chatgpt-enterprise-aws-marketplace)

OpenAI 宣布 ChatGPT Enterprise 现已上架 AWS Marketplace。企业可直接利用现有的 AWS 采购与账单关系简化软件购买与部署流程。

### [Kuken Industries searches 70 years of drawings in minutes](https://openai.com/index/kuken)

Kuken Industries 利用 OpenAI API 构建了智能检索系统，用以查找长达 70 年的冷却塔设计图纸。工程人员的单次图纸检索时间从近 1 小时缩短至 4.5 分钟。

### [Nemotron-Personas-Finance-Japan: A Synthetic Dataset Capturing Japan's Demographics and Financial Context](https://huggingface.co/blog/nvidia/nemotron-personas-finance-japan)

NVIDIA 发布了涵盖日本人口统计特征与金融背景的合成数据集 Nemotron-Personas-Finance-Japan。该数据集旨在帮助开发者训练和评估适配日本本地金融场景的 AI 模型。

### [Your Experts Have Partners. There's HOPE for Keeping Them Together](https://huggingface.co/blog/amazon/higher-order-pruning-experts)

Amazon 团队在 Hugging Face 博客分享了高阶专家剪枝技术 HOPE（Higher-Order Pruning of Experts）。该方案关注混合专家模型中专家节点之间的协同关系，在剪枝压缩模型的同时能更好地保持模型性能。
