## 版本概览

Pi 1.7.0 版本正式发布，重点带来了终端会话恢复机制、Codemode 图像生成增强以及 GitHub Copilot 的 Prompt 缓存优化。此外，该版本调整了多个云端模型的默认映射，并彻底删除了代码库中的遥测相关代码。

## 逐版本解读

### Pi 1.7.0（2026-11-27）

**新增** —— 支持基于 OSC 7577 协议的终端会话恢复功能，兼容的终端在重启后可自动恢复包含原始 Profile、工具限制（如 `--tools`、`--no-extensions`、`-e`、`--skill`、`--system-prompt` 等）和指令的会话（详见 [Terminal setup](https://docs.pi.dev/latest/terminal-setup#program-resume) 及 [Program Resume Protocol](https://www.superlogical.com/rex/docs/build/program-resume)）；新增命令行参数 `--agent-dir <dir>` 对应 `PI_CODING_AGENT_DIR`。Codemode 现已整合 Radius 图像生成模型，并在 `models.generateImages()` 中新增第三个可选参数 `{ aspectRatio, size }`（详见 [Codemode](https://docs.pi.dev/latest/codemode#generate-images)）。GitHub Copilot 在支持的 Claude 5.x 与 GPT-6 模型上切换思考层级或工具时能够保留 Prompt 缓存，同时支持缓存预热（详见 [Settings](https://docs.pi.dev/latest/settings#model-and-thinking)）。

**改动** —— 默认模型进行了多项更新：Cloudflare Workers AI 与 AI Gateway 默认模型变更为 `@cf/zai-org/glm-5.3`；`ant-ling` 默认模型更新为 `Ling-3.1-flash`（`thinkingFormat: "ant-ling"` 作为 `deepseek` 的已废弃别名保留，由 @lvisei 贡献，参见 [#11800](https://github.com/earendil-works/pi/pull/11800) 与 [PR](https://github.com/lvisei)）；Qwen Token Plan 个人版使用 `qwen4-max` 替代已被收回的 `qwen4-max-preview`。在 Copilot Claude 与 GPT-6 模型中修改思考层级与工具时保留缓存，GPT-5.3 Codex 及 MAI-Code 支持中途接收系统消息（参见 [#12316](https://github.com/earendil-works/pi/issues/12316)）。

**修复** —— 修复了在使用方向键选中搜索结果时 `/llama` 下载模型会误下载输入框文本而非高亮选项的问题（参见 [#12465](https://github.com/earendil-works/pi/issues/12465)）；修复了扩展编辑器和会话重命名中快捷键提示显示错误或硬编码的问题，现已统一纠正为 `tui.input.submit` 快捷键名称。

**破坏性变更** —— 彻底删除了遥测上报功能及相关 API（`/api/report-install`）、配置项 `enableInstallTelemetry`（`SettingsManager.getEnableInstallTelemetry()` / `setEnableInstallTelemetry()`）与环境变量 `PI_TELEMETRY`。升级后如有关联脚本或插件引用了这些配置，请及时移除相关依赖。

## 升级建议

推荐所有用户升级至 Pi 1.7.0。使用遥测配置的自定义自动化脚本在升级前需进行彻底清理；依赖终端长会话维护的开发者建议搭配支持 OSC 7577 的终端体验会话无缝恢复功能。
