## 版本概览

本期发布了 Pi 1.0.1 版本，带来了 Nix flake 支持、MCP 服务器项目级配置、Cloudflare Clef 分类器以及一系列安全性修复与体验改进。

## 逐版本解读

### Pi v1.0.1（2026-10-03）

**新增** —— 引入了面向 macOS 和 Linux 的 Nix flake（nix run github:earendil-works/pi/stable 与 nix profile add github:earendil-works/pi/stable，参见 https://pi.dev/docs/latest/quickstart#1-install-pi 以及 https://github.com/earendil-works/pi/pull/9137）；支持通过 .pi/mcp.json 和 /mcp 进行 MCP 服务器的项目级覆盖（参见 https://pi.dev/docs/latest/mcp#configure-servers 与 https://github.com/earendil-works/pi/issues/10277）；增加 OAuth 客户端 ID 元数据文档（CIMD）支持以简化授权服务器配置（参见 https://pi.dev/docs/latest/mcp#authenticate-with-oauth 与 https://github.com/earendil-works/pi/issues/10302）；支持为任意工具注册渲染器 pi.registerToolRenderer()（参见 https://pi.dev/docs/latest/extensions#tool-rendering 与 https://github.com/earendil-works/pi/issues/10285）；集成 Cloudflare Clef 与 Clef Flash 分类器（参见 https://pi.dev/docs/latest/models#use-classifier-models、https://github.com/earendil-works/pi/pull/10316 与 https://github.com/earendil-works/pi/pull/10322）；在 /login 与 /mcp 界面中为 OAuth 登录添加了复制快捷键（app.message.copy，默认 ctrl+x）。

**改动** —— 全局 npm 安装的 pi update 现在会推荐迁移到由 pi.dev 安装程序管理的版本；对话中添加或重定义的 Anthropic 工具现在以内联方式定义，以保持提示词缓存。

**修复** —— 修复了依赖解析中的漏洞，通过将 brace-expansion 锁定为 5.0.12 作为直接依赖（GHSA-q2hr-2g5m-vwhr 等，https://github.com/earendil-works/pi/issues/10288）；修复了 --models 尾随逗号导致多出一个模型的问题（https://github.com/earendil-works/pi/issues/10334）；修复了死循环输出导致 codemode 脚本内存崩溃的问题（https://github.com/earendil-works/pi/issues/10283）；修复了扩展通过 Image 渲染的图像在 Kitty、Ghostty、WezTerm 和 Warp 中不显示的问题（https://github.com/earendil-works/pi/issues/10292）。

## 升级建议

本次更新包含了重要的安全修复与功能增强，建议所有用户升级到最新版本。全局 npm 用户可考虑按照提示迁移至官方推荐的托管安装方式。
