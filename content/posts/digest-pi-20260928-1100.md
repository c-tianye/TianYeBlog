## 版本概览

本期更新包含 Pi 0.85.0 和 0.85.1 两个版本。本次更新重点带来了 Claude 思考强度的持久化保持、全屏转录记录交互增强、外部会话恢复能力，并迅速跟进了 GPT-6 Astra 支持以及针对 SDK 导入等关键问题的热修复。

## 逐版本解读

### Pi 0.85.1（2026-09-05）

**新增**

- 支持 GPT-6 Astra 模型，可通过 OpenAI API 密钥和 OpenAI Codex 订阅进行调用，详见 [API Keys](https://pi.dev/docs/latest/providers#api-keys) 与 [OpenAI Codex](https://pi.dev/docs/latest/providers#openai-codex)。
- 全屏模式下支持按住 Alt 键实现 5 倍速滚轮滚动（[#9166](https://github.com/earendil-works/pi/pull/9166) by [@xl0](https://github.com/xl0)）。

**修复**

- 修复模型和思考选择器中可配置保存快捷键的问题（[#9149](https://github.com/earendil-works/pi/pull/9149) by [@rwachtler](https://github.com/rwachtler)）。
- 修复因 0.85.0 误发内部实验代码及依赖导致的 SDK 导入失败问题；实验性客户端、插件子路径以及相关服务命令现已改为源码模式并通过 `pi-test.sh` 运行，支持的本地 SDK 和 stdio RPC API 保持不变（[#9132](https://github.com/earendil-works/pi/issues/9132)）。
- 修复鼠标悬停改变选中项并重新居中自动补全与设置列表，导致点击选中错误条目的问题。
- 修复针对 GPT-5.6+ Responses 模型的长提示缓存请求，将参数修正为 `prompt_cache_options.ttl: "30m"` 而非 `prompt_cache_retention: "24h"`。

### Pi 0.85.0（2026-09-04）

**新增**

- 持久化 Claude 思考强度（Persistent Claude thinking effort）：Anthropic 传输层可保留轮次间的思考强度设置，并在签名思考不匹配时安全恢复，详见 [Model Configuration](https://pi.dev/docs/latest/models#model-configuration)。
- 全屏转录记录控件（Fullscreen transcript controls）：在滚动转录记录时可一键跳转至最新消息，并支持内嵌工作状态指示器，详见 [TUI Fullscreen Viewport](https://pi.dev/docs/latest/keybindings#tui-fullscreen-viewport)。全屏向上滚动时提供可点击的 "Jump to latest message" 标签和 `tui.altScreen.bottom` 快捷键（[#9080](https://github.com/earendil-works/pi/pull/9080) by [@rwachtler](https://github.com/rwachtler)）。
- 可恢复内存会话（Restorable in-memory sessions）：SDK 支持通过 `SessionManager.inMemory()` 恢复外部管理的会话条目（[#8980](https://github.com/earendil-works/pi/pull/8980) by [@y-nk](https://github.com/y-nk)），详见 [Session Management](https://pi.dev/docs/latest/sdk#session-management)。
- 继承支持 OpenAI 兼容的 `vllmPriority` 和 `supportsMaxOutputTokens` 模型配置，用于 vLLM 调度优先级和 OpenAI Responses 输出 token 上限（[#9004](https://github.com/earendil-works/pi/pull/9004) by [@AppleDannyClegg](https://github.com/AppleDannyClegg)，[#8941](https://github.com/earendil-works/pi/pull/8941) by [@scturtle](https://github.com/scturtle)）。
- 继承关系代数连接符号的 LaTeX 渲染支持（[#9050](https://github.com/earendil-works/pi/pull/9050) by [@haoqixu](https://github.com/haoqixu)）。
- 支持通过 `/login meta` 登录 Meta（Muse 订阅）并自动刷新模型 API 密钥，同时支持 `META_API_KEY` 环境变量。

**改动**

- 将流式工作指示器移入默认编辑器边框，并将默认加载动画与标签颜色匹配思考层级边框色；自定义编辑器仍保留独立指示器除非主动接入（[#8799](https://github.com/earendil-works/pi/pull/8799) by [@cristinaponcela](https://github.com/cristinaponcela)）。
- 降低大转录记录下的全屏搜索延迟，通过缓存未变动的搜索结果、索引 ASCII 序列以及仅高亮可见匹配项提升性能（[#8800](https://github.com/earendil-works/pi/pull/8800) by [@cristinaponcela](https://github.com/cristinaponcela)）。

**修复**

- 修复 Linux musl 系统下受管 `fd` 与 `ripgrep` 的下载问题（[#9070](https://github.com/earendil-works/pi/pull/9070) by [@Charlie0113-T](https://github.com/Charlie0113-T)）。
- 从 `/model` 中移除不可用的 Grok Build 0.1 继承模型（[#9093](https://github.com/earendil-works/pi/pull/9093) by [@Jaaneek](https://github.com/Jaaneek)）。
- 修复继承的提供商流式输出产生不兼容事件序列和自定义工具调用增量的问题。
- 恢复 `@earendil-works/pi-coding-agent/client` 兼容性入口点。
- 修复继承的 Qwen 个人 Token 计划目录以包含 Qwen3.8 Flash（[#9021](https://github.com/earendil-works/pi/issues/9021)）。
- 修复继承的 OpenAI Codex SSE 解析逻辑，以正确处理未以空行结尾的终止事件（[#9047](https://github.com/earendil-works/pi/issues/9047)）。
- 修复继承的 GitHub Copilot Claude Fable 5 请求未发送所选推理层级的问题（[#8961](https://github.com/earendil-works/pi/issues/8961)）。
- 修复继承的 Baseten GLM-5.2 模型错误提示支持图像输入的问题（[#8293](https://github.com/Panoplos) by [@Panoplos](https://github.com/Panoplos)）。
- 修复仅启用 Bash 工具时技能（Skills）不可用的问题（[#8552](https://github.com/earendil-works/pi/pull/8552) by [@xl0](https://github.com/xl0)）。
- 修复并发会话共享时发生相互覆盖的问题（[#8613](https://github.com/earendil-works/pi/pull/8613) by [@wutongyuonce](https://github.com/wutongyuonce)）。
- 修复图像方向等渲染相关问题。

## 升级建议

建议所有使用 SDK 或使用 OpenAI Codex / Claude 系列模型推理的用户直接升级到 0.85.1 版本。若此前升级至 0.85.0，请务必更新以解决 SDK 导入异常和模型选择器快捷键问题。
