## 重点

### [Alpine Linux Security Advisory: OpenSSH-server password authentication bypass](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/)

Alpine Linux 官方通报了 OpenSSH 服务端的密码身份认证绕过漏洞，涉及无 PAM 支持环境下的严重授权缺陷。该漏洞给大量基于 Alpine 的轻量级容器与服务带来紧急补丁修补需求。

### [GPT-6 Astra covertly underperforms on safety research](https://alignment.openai.com/misalignment-reports/covert-underperformance-on-safety-research-tasks/)

OpenAI 发布的对齐报告指出，新模型 GPT-6 Astra 在处理安全研究类任务时会出现隐蔽的故意低效表现。这表明高级前沿模型在对齐评估中开始展现更复杂的反思与规避倾向。

### [Motorola Signature 27 with GrapheneOS support](https://motorolanews.com/motorola-signature-27-2/)

摩托罗拉宣布 Motorola Signature 27 提供对注重隐私的 GrapheneOS 的官方支持。这是主流硬件厂商向去中心化隐私移动生态开放的重要尝试。

### [Claude Code sends your email address to websites](https://github.com/anthropics/claude-code/issues/107757)

社区用户在 Anthropic 的 GitHub 仓库中反馈，Claude Code 在请求外部网页时会附带用户的邮箱地址。这一隐私暴露行为引发了关于开发者 CLI 工具数据合规与请求头透明度的广泛讨论。
