## 版本概览

本期包含 Pi v0.99.0 版本，这一批更新的整体主题是引入了强大的 Codemode 与 MCP 生态支持、增强的终端主题适配以及更灵活的虚拟模型和工具链扩展能力。

## 逐版本解读

### Pi v0.99.0（2026-09-29）

**新增** —— 引入了 Codemode 和 MCP，允许模型在沙箱中运行 JavaScript 并并行调用工具（https://pi.dev/docs/latest/mcp https://pi.dev/docs/latest/cli#enable-codemode）；默认采用终端自身的调色板作为系统主题（https://pi.dev/docs/latest/themes#use-your-terminals-colors）；支持通过 /login openai 使用 ChatGPT 订阅（https://pi.dev/docs/latest/providers#authenticate-interactively）；支持虚拟模型与分类器模型（https://pi.dev/docs/latest/virtual-models https://pi.dev/docs/latest/cli#how-codemode-works https://pi.dev/docs/latest/llama-cpp#classification）。添加了内置的 codemode、工具搜索和 MCP 支持（https://github.com/earendil-works/pi/issues/10040）；增加了用于编排工具的扩展工具 API（https://pi.dev/docs/latest/extensions#tool-exposure）；当扩展覆盖内置工具、命令或标志时给出警告（https://github.com/earendil-works/pi/pull/10174 by @cristinaponcela）；增加了实验性虚拟模型、ChatGPT 登录集成、系统主题、颜色格式支持、llama.cpp 聊天模型的分类器以及全屏鼠标滚轮滚动设置（https://github.com/earendil-works/pi/issues/9758）。

**改动** —— 调整了多项内部架构、工具执行与扩展生命周期的处理逻辑，优化了终端 TUI 渲染性能与各主流大模型提供商的兼容性。

**修复** —— 修复了多起社区反馈的崩溃、状态同步及边缘情况下的异常问题（涉及相关 PR 与 issue 链接：https://github.com/earendil-works/pi/issues/9098、https://github.com/earendil-works/pi/issues/9803、https://github.com/earendil-works/pi/issues/9784、https://github.com/earendil-works/pi/pull/9901、https://github.com/davidbrai、https://github.com/earendil-works/pi/issues/8896、https://github.com/earendil-works/pi/pull/10020、https://github.com/rwachtler、https://github.com/earendil-works/pi/issues/9965、https://github.com/earendil-works/pi/issues/9786、https://github.com/earendil-works/pi/issues/9863、https://github.com/earendil-works/pi/issues/9982、https://github.com/earendil-works/pi/issues/9990、https://github.com/earendil-works/pi/issues/9996、https://github.com/earendil-works/pi/issues/10000、https://github.com/earendil-works/pi/issues/10077、https://github.com/earendil-works/pi/pull/10158、https://github.com/earendil-works/pi/issues/9973、https://github.com/earendil-works/pi/pull/10039、https://github.com/christianklotz、https://github.com/earendil-works/pi/issues/9999、https://github.com/earendil-works/pi/pull/10136、https://github.com/earendil-works/pi/issues/9944、https://github.com/earendil-works/pi/issues/8938、https://github.com/earendil-works/pi/pull/9957、https://github.com/earendil-works/pi/issues/10026、https://github.com/earendil-works/pi/issues/9210、https://github.com/earendil-works/pi/issues/9506、https://github.com/earendil-works/pi/issues/9674、https://github.com/earendil-works/pi/issues/10034、https://github.com/earendil-works/pi/issues/9678、https://github.com/earendil-works/pi/issues/10047、https://github.com/earendil-works/pi/issues/9974）。
