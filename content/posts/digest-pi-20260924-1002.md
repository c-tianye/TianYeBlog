## 版本概览

本次更新带来了 Pi 0.86.0 版本，主要聚焦于提示词缓存优化、会话与诊断机制增强，以及模型配置的灵活性提升。

## 逐版本解读

### Pi 0.86.0（2026-09-19）

**新增** —— 引入了提示词缓存预热功能（Prompt cache warming），通过成本感知刷新在长工具运行和空闲时保持缓存有效。参见 [Cache Warming](https://pi.dev/docs/latest/settings#cache-warming)。新增了 /bug 报告命令，可通过脱敏诊断、可选的 transcripts 或导出的 ZIP 压缩包来报告问题，参见 [Reporting Bugs](https://pi.dev/docs/latest/sessions#reporting-bugs)。支持 Transcript 感知的提示词和工具更新，在恢复和分支导航时保持指令与工具变更同时保留缓存前缀，参见 [before_agent_start](https://pi.dev/docs/latest/extensions#before_agent_start)。新增了离线 Radius 模型目录，可立即选择 Radius 模型并在可用时叠加缓存与实时目录，参见 [Radius](https://pi.dev/docs/latest/providers#radius)。支持按模型配置压缩预算，可按模型配置保留与近期 Token 预算，参见 [Per-model overrides](https://pi.dev/docs/latest/compaction#per-model-overrides)。

**新增（其他）** —— 增加了转录支持的中途会话系统提示词和工具变更（#9548），详情见 [Entry Types](https://pi.dev/docs/latest/session-format#entry-types) 与 [PR 9548](https://github.com/earendil-works/pi/pull/9548)。新增了针对 Fireworks Messages 模型的继承原生延迟工具加载（#9323）。添加了分支摘要、压缩摘要和技能调用条目的点击切换功能。添加了公共 Radius 模型目录以便即时和离线模型选择。新增了用于通过配置的提供程序调用扩展模型的 `ctx.modelRegistry.stream()` 与 `streamSimple()`（#8964）。新增了通过 `compaction.modelOverrides` 的每模型保留与保持近期 Token 设置（#8133）。添加了用于覆盖或禁用 Anthropic 服务端回退模型的 `compat.allowedFallbackModels` 配置（#9294）。添加了来自 `pi.on()` 的取消订阅函数以供扩展丢弃事件处理程序（#8967）。导出了此前从包入口点中省略的扩展钩子事件和结果类型（#9642）。添加了用于向 Pi 开发者报告错误的 `/bug [description]` 命令。

**破坏性变更** —— 将继承的 pi-ai 提供程序流输入从 Context 更改为归一化的 TranscriptContext 值，自定义提供程序必须通过 getCurrentSystemPrompt() 和 getCurrentTools() 从 context.messages 中读取系统提示词和工具声明，参见 [Custom Streaming API](https://pi.dev/docs/latest/custom-provider#custom-streaming-api)。将继承的 `ToolCall.arguments` 和 `ToolResultMessage.details` 限制为兼容 JSON 的值，将 `ToolResultMessage` 更改为条件类型，并使 `JsonValue` 数组变为只读。`user_bash` 现在采用失败关闭（fail closed）策略：错误或无效的定义结果将中止命令，而不会调用后续处理器或在本地执行，返回 `undefined` 以为继传播，否则返回 `{ operations }` 或 `{ result }`（#9068）。

## 升级建议

本次升级包含多个破坏性变更（如自定义流 API 和 user_bash 失败关闭逻辑调整），建议在升级前仔细核对自定义提供程序与脚本的兼容性，并参考相关文档调整配置。
