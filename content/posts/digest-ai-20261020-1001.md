## 论文精选

### [Bellman Language Models: Solving the Recurring Decisions of LLM Agents](https://arxiv.org/abs/2610.24871v1)

### [The One-Pixel of Reasoning: One Truthful Relation Is Enough to Mislead LLM Agents](https://arxiv.org/abs/2610.24873v1)

来自 arXiv 的新预印本论文提出了一种单关系攻击（ORA），证明仅需一条事实真实的句子干扰关键推理关联，即可误导 LLM 智能体得出错误结论。

### [Teaching Code Agents to Ask Without Leaking Private Code](https://arxiv.org/abs/2610.24824v1)

最新预印本论文探讨了代码智能体向云端大模型求助时的隐私泄露风险，并设计了一种可以在不泄露本地私有代码的前提下有效提问的机制。

### [SpriteStage: Long Horizon Animation Generation via Progressive Scene Programming and Replay](https://arxiv.org/abs/2610.24869v1)

一篇预印本论文提出了 SpriteStage 框架，通过渐进式场景编程与回放技术，解决长时序动画生成中跨场景动作和剧情协调一致的难题。

### [Pattern-Driven Evaluation of LLM Code Optimization: Isolating Compiler-Transcendent Semantic Reasoning](https://arxiv.org/abs/2610.24835v1)

一篇新预印本论文推出了 PatternBench 基准，用于独立评估大模型在代码优化中是否真正具备超越传统编译器的语义推理能力。
