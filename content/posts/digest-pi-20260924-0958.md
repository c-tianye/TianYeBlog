## 版本概览

本期包含 Pi v0.87.1、v0.87.0 与 v0.86.1 三个版本，整体主题围绕前沿大模型集成（如 Claude Opus 5.5、GPT-6 系列、Grok 4.7 及 Meta Muse）、规范化的会话上下文边界控制、以及生命周期扩展钩子的增强展开。

## 逐版本解读

### Pi v0.87.1（2026-09-22）

**新增** —— 支持通过 GitHub Copilot 等受支持的服务提供商使用 Claude Opus 5.5、GPT-6 Sol 和 GPT-6 Luna 等前沿模型，并为 xAI 新会话默认启用 Grok 4.7。详情参见 [选择模型](https://pi.dev/docs/latest/models#select-a-model) 与 [提供商身份验证](https://pi.dev/docs/latest/providers#use-an-api-key-from-the-environment)。

**改动** —— 将 xAI 的默认模型更改为 Grok 4.7。

**修复** —— 修复了 Claude Fable 5.1 拒绝分轮压缩摘要的问题（通过 #9908 由 @davidbrai 提交，参见 [PR 9908](https://github.com/earendil-works/pi/pull/9908) 与 [@davidbrai](https://github.com/davidbrai)）；修复了缺失或无效的 --mode 值被静默忽略而不是报错并以非零状态码退出的问题（[Issue 9045](https://github.com/earendil-works/pi/issues/9045)）；修复了继承的纯图片用户消息因包含空文本部分而被某些 OpenAI 兼容提供商拒绝的问题（[Issue 9797](https://github.com/earendil-works/pi/issues/9797)）；修复了继承的 Anthropic OAuth 请求上报过时 Claude Code 版本的问题。

### Pi v0.87.0（2026-09-21）

**新增** —— 引入规范的会话上下文与扩展边界，允许在不重写历史的情况下编辑模型上下文并添加可操作的生命周期钩子（参见 [ContextEditEntry 与扩展事件](https://pi.dev/docs/latest/session-format#contexteditentry)）；提供全转录上下文扩展，支持针对每个请求进行系统消息转换（参见 [context_with_system](https://pi.dev/docs/latest/extensions#context_with_system)）；支持配置每模型的图像输入限制与调整大小档案（参见 [图像输入限制](https://pi.dev/docs/latest/models#image-input-limits)）。

**改动** —— 增强了追加式模型上下文编辑能力、可操作的 turn_end 与 agent_before_settle 扩展边界、保留无压缩输入以及根据 models.json 中的 inputLimits.images.resize 应用每模型图像调整大小配置（[Issue 9631](https://github.com/earendil-works/pi/issues/9631)）。

**修复** —— 修复了字符串上下文编辑替换产生无效的助手和工具结果消息内容而非文本块的问题；修复了不可见的上下文边界元数据和替换编辑导致新追加或替换的输入在其第一次提供商请求之前被压缩的问题；修复了编辑上下文记账同时丢弃在最新上下文编辑之后捕获的有效助手使用情况并在稍后的压缩使其陈旧后重用该使用情况的问题；修复了选定的错误重试和最终长度/溢出恢复在未来的提供商提供上下文中保留废弃模型尝试的问题。

**破坏性变更** —— 移除了继承的 shouldStopAfterTurn 代理选项，请改用 finishTurn 并返回 { action: "end" }；将 ContextEditEntry 添加到导出的 SessionEntry 联合中；使 SessionManager 成为 AgentSession 提供商上下文的规范；扩展了 TurnEndEvent 并将 AgentBeforeSettleEvent 添加到导出的 ExtensionEvent 联合中；将代理结算（agent_settled）处理程序请求的运行延迟到所有结算处理程序完成之后。

### Pi v0.86.1（2026-09-20）

**新增** —— 引入 Meta Muse 提供商，支持通过 /login meta 或 META_API_KEY 访问 Muse Spark 模型（参见 [Meta Muse 订阅](https://pi.dev/docs/latest/providers#meta-muse-subscription)）。

**改动** —— 在加载捆绑的 CLI 运行时之前启用了 Node 的持久编译缓存，从而减少了重复启动时间。

**修复** —— 修复了 /bug 描述丢弃粘贴诊断中换行符的问题；修复了 /bug 提示对用户取消和可重试提供商故障（如服务不可用）出现的错误；修复了容器和没有 WSLg 的 WSL 中剪贴板复制失败的问题（通过恢复 OSC 52 后备并为 WSL 验证了 Windows 剪贴板后端，参见 [Issue 9688](https://github.com/earendil-works/pi/issues/9688)）；修复了继承的 z.ai 提示词太长错误未被识别为上下文溢出的问题（[Issue 9805](https://github.com/earendil-works/pi/issues/9805)）；修复了继承的 Cerebras 模型宣传不受支持的严格工具模式而导致混合使用严格与非严格工具时发生 HTTP 400 错误的问题（通过 #9804 由 @EdenGottlieb 提交，参见 [PR 9804](https://github.com/earendil-works/pi/pull/9804) 与 [@EdenGottlieb](https://github.com/EdenGottlieb)）。

## 升级建议

由于 v0.87.0 引入了多项架构层面的破坏性变更（如移除 shouldStopAfterTurn 及规范化 SessionManager），建议开发人员在升级前仔细查阅相关 API 迁移指南。对于日常用户，本次升级带来了更丰富的前沿大模型选择与更高的运行稳定性，建议尽快升级至最新版本。
