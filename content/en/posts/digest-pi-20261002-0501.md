## Versions overview

This release brings Pi 1.0.0 with fullscreen TUI by default, leaner codemode prompt token usage, image generation, and hardened MCP OAuth and login integrations.

## Version by version

### Pi 1.0.0 (2026-10-01)

**New** — The TUI now runs fullscreen by default while supporting regular terminal scrollback configurations. Introduced a leaner codemode with roughly 40% fewer prompt tokens and error recovery guidance. Scripts can now perform image generation via models.generateImages(). Added Radius login and one-step MCP server provisioning, alongside Anthropic copy code login for headless setups where the browser runs on another machine. MCP OAuth security was hardened with oauth.authServerMetadataUrl, RFC 9207 iss checks, per-server credentials, and step-up sign-in preserving granted scopes. Additionally, a quietStartup: "header" option was introduced to keep only version and key hints.

**Changed** — The default TUI mode is now fullscreen, with tuiMode set to "regular" or --tui-mode regular available to preserve traditional scrollback. The /login menu has been reorganized to feature Radius sign-in prominently and automatically configure global mcp.json upon success. The provider documentation page was renamed to Providers with updated configuration sections. MCP OAuth credentials are now stored per server name and URL to prevent account collisions (#10266, #10186, #10236, #10255). Codemode descriptions and error handling have also been heavily optimized for lower token usage and better recovery hints.

## Upgrade notes

As a major milestone release, 1.0.0 introduces default fullscreen TUI and significantly optimized codemode features; upgrading is highly recommended for all users to enjoy improved performance and features.
