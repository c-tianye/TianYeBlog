## Versions overview

This release highlights Pi version 1.2.0. Key updates include per-key model list filtering for OpenRouter, published JSON configuration schemas, remote session OSC 52 clipboard forwarding, and breaking refinements to extension start events and session busy states.

## Version by version

### Pi 1.2.0 (2026-10-12)

**New**

- Per-key OpenRouter model lists — With an OpenRouter key, Pi lists only the chat models permitted for that key, along with context size, max output, and pricing (including custom base URLs/regional endpoints in models.json), and caches them for offline use (see [OpenRouter](https://pi.dev/docs/latest/providers#openrouter)).
- Published configuration schemas — Support for adding $schema to settings.json, models.json, keybindings, and themes to enable editor auto-completion and validation (see [Settings](https://pi.dev/docs/latest/settings), [Models](https://pi.dev/docs/latest/models), [Keybindings](https://pi.dev/docs/latest/keybindings), and [Themes](https://pi.dev/docs/latest/themes)).
- Clipboard copies over remote sessions — Setting PI_CLIPBOARD_OSC52=1 forwards copied text to a remote client clipboard when Pi cannot automatically detect a remote session (see [Pi Process Configuration](https://pi.dev/docs/latest/environment-variables#pi-process-configuration)).
- Codemode improvements — Tool declarations display input constraints (such as integer, minimum/maximum, default), and codemode rows display elapsed and total execution time (see [Codemode](https://pi.dev/docs/latest/codemode)).
- Extension-triggered runs before_agent_start — Runs initiated via pi.sendMessage(..., { triggerTurn: true }) follow the same setup lifecycle as user prompts (see [Events and concurrency](https://pi.dev/docs/latest/extensions#events-and-concurrency)).
- reachesTools in tool definitions — Allows meta-tools like codemode and tool_search to declare reachable tools, helping the MCP extension wait for required servers.
- Tool namespace aliases — Added alias matching for codemode's describeNamespace() and the namespace option of searchTools(), mapping MCP namespaces to server names.

**Changed**

- Updated pi mcp list --json output — Now reports resources: true for servers offering resources instead of returning numeric counts for resources and resourceTemplates; Pi no longer enumerates resources upon connection ([#10526](https://github.com/earendil-works/pi/issues/10526)).

**Fixed**

- Fixed model filtering and offline cache synchronization for OpenRouter ([#10353](https://github.com/earendil-works/pi/issues/10353)).
- Resolved race conditions and concurrent run crashes during session setup ([#10739](https://github.com/earendil-works/pi/pull/10739)).

**Breaking**

- Configuration and theme schemas moved to https://pi.dev/schemas/*.schema.json — The theme schema is now located at https://pi.dev/schemas/theme.schema.json, and startup theme validation is strictly enforced. Users must update theme $schema references, relocate reusable colors under vars, and remove unsupported metadata properties ([#9880](https://github.com/earendil-works/pi/pull/9880), [#10751](https://github.com/earendil-works/pi/pull/10751)).
- before_agent_start event structure change — Now fires for idle runs started by pi.sendMessage(..., { triggerTurn: true }). BeforeAgentStartEvent is now a union based on messageType: "user" contains prompt and images, while "custom" carries starting message without prompt ([#10267](https://github.com/earendil-works/pi/issues/10267), [#5581](https://github.com/earendil-works/pi/issues/5581), [#10739](https://github.com/earendil-works/pi/pull/10739)).
- Session marked busy during run startup — Sessions are considered busy during startup and before_agent_start handlers (ctx.isIdle() returns false). pi.sendMessage() queues into the starting run rather than failing with "Agent is already processing", pi.sendUserMessage() requires deliverAs, and abort requests cancel the run once initialized ([#10739](https://github.com/earendil-works/pi/pull/10739)).
- Changed pi mcp list --json format — Replaces numeric counts with a boolean resources flag, requiring updates to external parsing scripts ([#10526](https://github.com/earendil-works/pi/issues/10526)).

## Upgrade notes

Upgrading to 1.2.0 is recommended. Before updating, ensure custom theme files conform to the new schema validation rules and verify extension handlers handling before_agent_start support the discriminated union event types.
