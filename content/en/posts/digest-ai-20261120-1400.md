## Overview

This issue features the latest preprint papers from arXiv, with no official lab releases in this update. Key topics include understanding RL post-training dynamics in Diffusion Transformers, memory serving optimization for hybrid LLMs, and high-fidelity metric monocular depth estimation across video and image modalities.

## Papers

### [RL Post-Training in Diffusion Transformers Is Activation Steering](https://arxiv.org/abs/2611.26627v1)

This preprint paper investigates the underlying mechanisms behind reinforcement learning post-training in Diffusion Transformers, suggesting that capability gains can largely be framed as activation steering rather than overly complex input-dependent transformations.

### [TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming](https://arxiv.org/abs/2611.26619v1)

Addressing the heterogeneous cache requirements in hybrid open-weight LLMs, this preprint presents TideCache, a serving system on CPU-GPU superchips that dynamically manages cache residency across unified memory via layer-wise streaming.

### [One Prior, Two Dynamics: Repurposing Video Diffusion Transformers for Self-Supervised Latent Action Learning](https://arxiv.org/abs/2611.26617v1)

This paper introduces O²LaF, a framework that repurposes a pretrained video diffusion transformer to provide a shared prior for both forward and inverse dynamics in self-supervised latent action discovery.

### [Depth Pro 2: Sharp and Temporally Consistent Metric Monocular Depth](https://arxiv.org/abs/2611.26603v1)

Addressing the common trade-off between temporal consistency and boundary sharpness in monocular depth estimation, this preprint paper presents Depth Pro 2, a unified model delivering sharp, full-resolution metric depth for both still frames and continuous video.

## Also worth reading

- [Active Feature Acquisition by Distilling an Oracle Teacher](https://arxiv.org/abs/2611.26598v1) — This work proposes an Active Feature Acquisition framework that distills an explicit oracle teacher policy to optimize budget-constrained feature collection.
