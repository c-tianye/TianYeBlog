## Overview

This edition of AI research highlights focuses on deep optimizations in memory mechanisms and reasoning efficiency for large language models. Recent preprints present novel frameworks for model weight-space memory consolidation, process reward evaluation, agent cost control, and specialized domain benchmarks.

## Papers

### [Instant Weight-Space Consolidation for Long-Term Memory in LLMs](https://arxiv.org/abs/2611.20759v1)

A new paper proposes an instant weight-space consolidation mechanism for long-term memory, addressing the limitation where text-retrieval agent memory systems fail to evolve the model itself over time.

### [GPRM: Global Perspective Process Reward Model](https://arxiv.org/abs/2611.20755v1)

Researchers introduce the Global Perspective Process Reward Model (GPRM), enhancing step-level evaluation in multi-step reasoning by incorporating global awareness of both prior and subsequent steps.

### [GainCtrl: Predicting Remaining Gains for Efficient LLM Agent Execution](https://arxiv.org/abs/2611.20736v1)

Addressing the cost of repeated tool-use attempts, a new paper introduces a method to predict remaining execution gains and terminate redundant steps early without compromising task performance.

### [Can LLMs Give Good Product Advice? A Framework for Diagnosing Failures](https://arxiv.org/abs/2611.20734v1)

This paper presents a diagnostic framework to evaluate LLM-generated product advice and systematically identify underlying failure modes when user requirements are missed.

### [MemEmo: Evaluating Emotion in Memory Systems](https://arxiv.org/abs/2611.20733v1)

Aiming to improve personalized long-context interaction, researchers introduce MemEmo, a benchmark evaluating how effectively memory systems process affective and emotional information.

### [Routing Beyond Task Categories: A Cost-Aware LAB-Bench Study](https://arxiv.org/abs/2611.20732v1)

A new study explores cost-aware model routing by combining task structural features to optimize model selection within fixed inference budgets.

### [ANCHOR: Cluster-Grounded 5W1H Extraction via Large-Small Model Collaboration](https://arxiv.org/abs/2611.20728v1)

Researchers propose ANCHOR, a collaborative framework combining large and small models with cluster-grounding to accurately extract structured 5W1H event information.

### [PEETS: Preference-aware Embeddings with Explicit Tree Structure for Auxiliary Product Bundling](https://arxiv.org/abs/2611.20726v1)

Addressing SKU-level granularity ambiguity in travel cross-selling, a new paper introduces PEETS, incorporating explicit tree structures into preference-aware embeddings.

### [AgentFaultBench: State-Verified Evaluation of Tool-Fault Recovery](https://arxiv.org/abs/2611.20711v1)

This paper introduces AgentFaultBench, evaluating LLM agents' tool-error recovery capabilities through state-verified execution in isolated environments.

### [A First Look at System One Decision Models for Malware Detection](https://arxiv.org/abs/2611.20699v1)

Researchers evaluate single-forward-pass System One decision models for malware detection, offering calibrated confidence scores alongside analyst-readable outputs.

### [IndustrialKnowEval: A Benchmark for Evaluating Multi-Level Industrial Knowledge in LLMs](https://arxiv.org/abs/2611.20695v1)

A new paper introduces IndustrialKnowEval, a 43,282-sample benchmark designed to assess LLMs across multi-level cognitive industrial domain tasks.

### [SpeCal: Spectral Calibration for Unsupervised RLVR](https://arxiv.org/abs/2611.20691v1)

To reduce reliance on ground-truth verifiers, researchers propose SpeCal, a spectral calibration technique for unsupervised reinforcement learning with verifiable rewards.

## Takeaway

Recent preprints showcase significant progress in evolving model memory architectures, optimizing agent execution efficiency, and establishing specialized industrial and affective benchmarks.
