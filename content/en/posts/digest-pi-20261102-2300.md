## Versions overview

This release introduces Pi v1.5.0, featuring extension update changelogs, rendering optimizations for streaming, custom update commands, and new model integrations.

## Version by version

### Pi 1.5.0 (2026-11-02)

**New** — Added extension update changelogs (https://pi.dev/docs/latest/packages#show-a-changelog), faster streaming with incremental parsing (https://pi.dev/docs/latest/tui#keep-rendering-responsive), custom self-update commands (https://pi.dev/docs/latest/cli#custom-update-command), and GPT-6.1 Terra model support (https://pi.dev/docs/latest/cli#models).

**Changed** — Extensions can now display changelogs after updates (#5958, #8790), `pi.exec()` accepts a maxBuffer option with a truncated status (#11360), device-code logins open verification pages and copy codes on Enter (#9282, #9301), `pi update` supports wrappers or package managers (#7756, #5607), and added persisted messageId and timestamp to MarkdownTransformContext (#7952).

**Fixed** — Resolved multiple runtime issues, terminal quirks, and custom UI component bugs.

**Breaking** — Tool argument validation now runs on `@earendil-works/pi-schema`, meaning certain TypeBox features outside JSON Schema are no longer supported for tool arguments (https://pi.dev/docs/latest/extensions#tool-parameter-schemas-and-typebox).

## Upgrade notes

This release includes breaking changes regarding tool argument validation and schemas, so please verify your extensions and tool definitions before upgrading.
