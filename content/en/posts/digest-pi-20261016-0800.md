## Versions overview

This release brings Pi version 1.3.0, focusing on cache optimizations, provider protocol adjustments, session sharing configurations, and various stability and environment compatibility fixes.

## Version by version

### Pi 1.3.0 (2026-10-15)

**New** — Choose where /share uploads: sessionShareDestination selects auto, gist, or radius. See Sessions and context and Export or share a session (links: https://pi.dev/docs/latest/settings#sessions-and-context https://pi.dev/docs/latest/sessions#export-or-share-a-session). Cache-preserving thinking level changes on OpenAI GPT-6. Kimi Code over Chat Completions: tools added mid-conversation no longer invalidate the prompt cache. models.json base URL overrides must now include /v1. See Providers (link: https://pi.dev/docs/latest/providers). Clean model switching: thinking from a previous model is dropped instead of being shown to the new model as text. Resumed sessions keep their active tools: --tools +name/-name applies on top of them. See Tools (link: https://pi.dev/docs/latest/settings#tools). Changing the thinking level mid-session on OpenAI GPT-6 models (API key) now keeps the prompt cache (#10853) (link: https://github.com/earendil-works/pi/issues/10853). Added the sessionShareDestination setting to choose automatic, GitHub gist, or Radius uploads for /share (#10870 by @vegarsti) (links: https://github.com/earendil-works/pi/issues/10870 https://github.com/vegarsti).

**Changed** — Changed the kimi-coding provider to use OpenAI Chat Completions at https://api.kimi.com/coding/v1, the protocol used by the official Kimi Code client (#10720) (link: https://github.com/earendil-works/pi/issues/10720). Changed model switching to drop thinking blocks from earlier assistant messages produced by a different model (#10995) (link: https://github.com/earendil-works/pi/issues/10995).

**Fixed** — Pinned internal Pi dependencies to exact release versions to prevent fresh installs from mixing incompatible packages (#10865) (link: https://github.com/earendil-works/pi/issues/10865). Fixed resumed sessions dropping tools activated during the session (#10785) (link: https://github.com/earendil-works/pi/issues/10785). Fixed stopping a codemode script or reaching its deadline waiting for a non-interruptible built-in to return on Bun (#10748) (link: https://github.com/earendil-works/pi/issues/10748). Fixed repeated codemode timeouts or aborts accumulating surviving workers (#10748) (link: https://github.com/earendil-works/pi/issues/10748). Fixed --model choosing a provider by catalog order when several providers offer the match (#10160) (link: https://github.com/earendil-works/pi/issues/10160). Fixed read line-range labels for numeric-string or null arguments in the TUI, session tree, HTML exports, and examples (#9887) (link: https://github.com/earendil-works/pi/issues/9887). Fixed the Nix flake build failing when a provider switched APIs (#10985) (link: https://github.com/earendil-works/pi/issues/10985). Fixed the Nix package putting its Node.js first on PATH (link: https://github.com/earendil-works/pi/issues/10519).

## Upgrade notes

Upgrading to Pi 1.3.0 is recommended for improved GPT-6 caching and Kimi Code stability. Note that kimi-coding base URL overrides must now include /v1.
