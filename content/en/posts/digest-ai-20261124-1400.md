## Papers

### [RepoClean: Evaluating Coding Agents on Repository-Level Obsolete Code Cleanup](https://arxiv.org/abs/2611.30350v1)

A new paper introduces RepoClean, a benchmark designed to evaluate LLM agents on identifying and safely removing obsolete code across entire repositories, addressing a key gap in evaluating software maintenance capabilities.

### [Verifiable On-Policy Distillation](https://arxiv.org/abs/2611.30325v1)

A new paper proposes Verifiable On-Policy Distillation (OPD), combining sparse rewards from verifiable reward reinforcement learning with dense teacher feedback to improve reasoning efficiency in language models.

### [AutoClip-DPZO: Practical Private Clipping Selection for Differentially Private Zeroth-Order LLM Fine-Tuning](https://arxiv.org/abs/2611.30352v1)

A new paper presents AutoClip-DPZO, solving the issue of high sensitivity to clipping thresholds in differentially private zeroth-order LLM fine-tuning without requiring prohibitive hyperparameter search costs.

### [MH-RAG-DIVE: Dynamic and Cost-Efficient Multi-Hop RAG Evaluation via Tree-Cached Dialogue Simulation](https://arxiv.org/abs/2611.30335v1)

A new paper introduces MH-RAG-DIVE, a framework that uses tree-cached interactive user simulations to perform realistic, dynamic, and cost-effective evaluation of multi-hop RAG systems.
