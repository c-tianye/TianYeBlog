## Overview

This update focuses entirely on recent preprints from arXiv. Key developments include exploring text-to-image autoregressive generation without prior language pretraining, enabling agents to synthesize functional physical CAD mechanisms, and advancing linear attention architectures.

## Papers

### [Text-to-Image Generative Modeling Without Language Pretraining](https://arxiv.org/abs/2610.26863v1)

A new preprint investigates whether language pretraining is essential for strong image generation, presenting Halcyon—an early-fusion multimodal autoregressive model trained entirely from scratch on image-text pairs that outperforms existing baselines with smaller scale.

### [OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory](https://arxiv.org/abs/2610.26860v1)

Addressing the limitations of multimodal LLMs relying purely on internal reasoning budgets, this paper proposes an evaluation and execution harness for visual agents combining external tool use and multimodal memory.

### [Can It Actually Work? Synthesizing Functional CAD Mechanisms](https://arxiv.org/abs/2610.26861v1)

Targeting the issue where generated CAD assemblies look plausible but fail physically, this study introduces an agent framework to synthesize and iteratively revise mechanism designs to satisfy functional requirements in simulation.

### [Reinforcement Learning with Visually Attributable On-Policy Self-Distillation](https://arxiv.org/abs/2610.26856v1)

This paper proposes an on-policy self-distillation approach with visual attribution for multimodal RL, mitigating error localization issues by disentangling visual evidence from textual reasoning corrections.

### [WeAct: Dynamic Weight Switching as Agent Actions](https://arxiv.org/abs/2610.26847v1)

To prevent catastrophic forgetting across long-horizon trajectories requiring heterogeneous skills, this preprint frames switching parameter weights dynamically as explicit agent actions.

### [Kronecker Delta Rule for Long Context Linear Attention](https://arxiv.org/abs/2610.26834v1)

The authors introduce KronLSTM, an architecture extending the xLSTM family with a Kronecker Delta Rule update mechanism for minimally invasive memory revision in long-context modeling.

## Also worth reading

- [Where is Physical RSI capability from? An Observational Scaling Law of LLM-as-policy](https://arxiv.org/abs/2610.26848v1) — An observational study characterizing the scaling behavior of physical recursive self-improvement in vision-language policies.

Recent preprints demonstrate steady progress toward training multimodal architectures from scratch and equipping agents with physically verified, long-horizon operational capabilities.
