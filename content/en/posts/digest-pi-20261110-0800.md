## Versions overview

Pi 1.5.1 is a major update featuring key capabilities across CLI authentication, context management, and diagram rendering. Highlights include shell login/logout commands, Anthropic message threads, idle cache warming, and refined OpenAI API compatibility fixes.

## Version by version

### Pi 1.5.1 (2026-11-09)

**New**

- Shell authentication commands — manage credentials without starting a session via `pi auth login <provider>` and `pi auth logout <provider>`. See [Credential commands](https://pi.dev/docs/latest/cli#credential-commands).

- Idle prompt cache warming — keeps eligible caches warm for up to 30 minutes between runs. See [cacheWarming](https://pi.dev/docs/latest/settings#model-and-thinking).

- Anthropic message threads — requests only send new messages while the server retains conversation state, with full-request fallback on context changes. See [Anthropic compatibility](https://pi.dev/docs/latest/models-configuration#anthropic-messages) and [PR #11545](https://github.com/earendil-works/pi/pull/11545).

- Richer Mermaid diagrams — support for pie charts, custom styles, and summaries. See [Display settings](https://pi.dev/docs/latest/settings#terminal-and-display) and [Markdown transformers](https://pi.dev/docs/latest/extensions#piregistermarkdowntransformertransformer-options).

- GitHub Copilot classifiers — access `Microsoft-Decision-1` via `codemode models.classify()`. See [Use classifier models](https://pi.dev/docs/latest/models#use-classifier-models).

- Package update summaries — `pi update --extensions` reports exact npm version or git commit changes. See [Update Pi or packages](https://pi.dev/docs/latest/cli#update-pi-or-packages), [PR #11707](https://github.com/earendil-works/pi/pull/11707), and [PR #11711](https://github.com/earendil-works/pi/pull/11711).

- Markdown transformer options — `pi.registerMarkdownTransformer()` adds `{ messageTypes }` selector for targeted rendering.

**Changed**

- Enhanced update CLI output — `pi update` now clearly distinguishes between unchanged, skipped, and warned package updates.

- Grep context retrieval — context lines are now fetched directly from ripgrep without extra file read calls.

**Fixed**

- Fixed HTTP 400 errors caused by sending `"tools": []` in OpenAI-compatible models when tools are disabled. See [Issue #11843](https://github.com/earendil-works/pi/issues/11843).

- Resolved issues related to remote execution and grep tool callbacks. See [Issue #9276](https://github.com/earendil-works/pi/issues/9276).

**Breaking**

- Custom `GrepOperations.readFile` callbacks are no longer called for context lines. To search remote systems, override grep's `execute()`. See [Remote Execution](https://pi.dev/docs/latest/extensions#remote-execution) and [Issue #9276](https://github.com/earendil-works/pi/issues/9276).

- OpenAI-compatible models omit `"tools": []` when tools are disabled. If your proxy setup requires tool fields once history contains tool calls, configure `compat.requiresToolsWithToolHistory: true`. See [Issue #11843](https://github.com/earendil-works/pi/issues/11843).

## Upgrade notes

Upgrading to Pi 1.5.1 is recommended for improved session context efficiency and caching benefits. Users relying on custom grep callbacks or proxy adapters in front of Anthropic/OpenAI models should review the breaking changes prior to upgrading.
