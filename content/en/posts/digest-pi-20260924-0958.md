## Versions overview

This release batch includes Pi v0.87.1, v0.87.0, and v0.86.1, centering around frontier model integrations (Claude Opus 5.5, GPT-6 series, Grok 4.7, and Meta Muse), standardized session context boundaries, and enhanced lifecycle extension hooks.

## Version by version

### Pi v0.87.1 (2026-09-22)

**New** — Use Claude Opus 5.5, GPT-6 Sol, and GPT-6 Luna through supported providers including GitHub Copilot, and default new xAI sessions to Grok 4.7. See [Choose a Model](https://pi.dev/docs/latest/models#select-a-model) and [Provider Authentication](https://pi.dev/docs/latest/providers#use-an-api-key-from-the-environment).

**Changed** — Changed the default xAI model to Grok 4.7.

**Fixed** — Fixed split-turn compaction summaries being refused by Claude Fable 5.1 (#9908 by @davidbrai, see [PR 9908](https://github.com/earendil-works/pi/pull/9908) and [@davidbrai](https://github.com/davidbrai)); fixed missing or invalid --mode values being silently ignored instead of reporting an error and exiting with a nonzero status ([Issue 9045](https://github.com/earendil-works/pi/issues/9045)); fixed inherited image-only user messages being rejected by some OpenAI-compatible providers because they included an empty text part ([Issue 9797](https://github.com/earendil-works/pi/issues/9797)); fixed inherited Anthropic OAuth requests reporting an outdated Claude Code version.

### Pi v0.87.0 (2026-09-21)

**New** — Canonical session context and extension boundaries to edit model context without rewriting history and add actionable lifecycle hooks (see [ContextEditEntry and extension events](https://pi.dev/docs/latest/session-format#contexteditentry)); full-transcript context extensions using context_with_system for per-request system-message transformations (see [context_with_system](https://pi.dev/docs/latest/extensions#context_with_system)); per-model image input limits and cache-safe resizing profiles (see [Image Input Limits](https://pi.dev/docs/latest/models#image-input-limits)).

**Changed** — Added append-only model-context edits, actionable turn_end and agent_before_settle extension boundaries, retain-none compaction input, and per-model image resize profiles applied via inputLimits.images.resize in models.json ([Issue 9631](https://github.com/earendil-works/pi/issues/9631)).

**Fixed** — Fixed string context-edit replacements producing invalid assistant and tool-result message content instead of text blocks; fixed context-invisible boundary metadata and replacement edits causing newly appended or replaced input to be summarized before its first provider request; fixed edited-context accounting discarding valid assistant usage captured after the latest context edit and reusing that usage after a later compaction made it stale; fixed selected error retries and final length/overflow recovery retaining abandoned model attempts in future provider context.

**Breaking** — Removed the inherited shouldStopAfterTurn agent option, use finishTurn and return { action: "end" } instead; added ContextEditEntry to the exported SessionEntry union; made SessionManager canonical for AgentSession provider context; expanded TurnEndEvent with required boundary fields and added AgentBeforeSettleEvent to the exported ExtensionEvent union; deferred runs requested from agent_settled handlers until all settled handlers finish.

### Pi v0.86.1 (2026-09-20)

**New** — Meta Muse provider integration allowing sign-in with Meta using /login meta or META_API_KEY to access Muse Spark models (see [Meta Muse subscription](https://pi.dev/docs/latest/providers#meta-muse-subscription)).

**Changed** — Enabled Node's persistent compile cache before loading the bundled CLI runtime to reduce repeat launch time.

**Fixed** — Fixed /bug descriptions dropping line breaks from pasted diagnostics; fixed /bug hints appearing for user cancellations and retryable provider failures; fixed clipboard copy failing in containers and WSL without WSLg by restoring the OSC 52 fallback and adding a verified Windows clipboard backend for WSL ([Issue 9688](https://github.com/earendil-works/pi/issues/9688)); fixed inherited z.ai Prompt too long errors not being recognized as context overflow ([Issue 9805](https://github.com/earendil-works/pi/issues/9805)); fixed inherited Cerebras models advertising unsupported strict tool schemas causing HTTP 400 errors (#9804 by @EdenGottlieb, see [PR 9804](https://github.com/earendil-works/pi/pull/9804) and [@EdenGottlieb](https://github.com/EdenGottlieb)).

## Upgrade notes

Since v0.87.0 introduces multiple architectural breaking changes such as removing shouldStopAfterTurn and standardizing SessionManager, developers should carefully check migration guides before upgrading. For general users, this batch brings powerful new frontier models and improved operational stability, making an upgrade highly recommended.
