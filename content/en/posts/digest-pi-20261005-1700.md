## Versions overview

This release covers Pi v1.0.3, focusing on Azure Foundry chat completions integration, Codemode image handling enhancements, terminal shortcut tweaks, and essential stability fixes.

## Version by version

### Pi v1.0.3 (2026-10-05)

**New** — Added Azure Foundry Chat Completions deployments starting with azure/deepseek-v4-pro, and updated Codemode to save generated images to temp files. See https://pi.dev/docs/latest/providers#azure-openai and https://pi.dev/docs/latest/codemode#generate-images (Ref: #9645, #9714 by @jsanter27, links: https://github.com/earendil-works/pi/issues/9645, https://github.com/earendil-works/pi/pull/9714, https://github.com/jsanter27)

**Changed** — Output files are now readable only by the user; Home/End now always move the editor cursor while transcript scrolling moved to Ctrl+Home/Ctrl+End (#10314, link: https://github.com/earendil-works/pi/issues/10314); Codemode image() saves each image to a temp file (#10310, link: https://github.com/earendil-works/pi/issues/10310).

**Fixed** — Fixed subscription logins failing after cancelled token refresh; fixed codemode failing after global updates and added restart hints (#10439, link: https://github.com/earendil-works/pi/issues/10439); fixed interactive sessions reporting read EIO or setRawMode EIO crashes when the terminal went away.

**Breaking** — Renamed the Azure provider from azure-openai-responses to azure. Rename the provider key in auth.json, models.json, and settings.json. Resumed sessions using the old provider will fall back to another model without prompt cache reuse (Ref: #9714, https://github.com/jsanter27, link: https://github.com/earendil-works/pi/pull/9714).

## Upgrade notes

Review the breaking changes regarding the Azure provider rename and update your configuration files before upgrading. It is highly recommended to upgrade to v1.0.3 for improved terminal stability and new features.
