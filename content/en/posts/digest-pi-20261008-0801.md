## Versions overview

This release cycle covers Pi 1.1.0, focusing on advanced model integrations, enhanced terminal interactivity, and refined toolchain configurations.

## Version by version

### Pi 1.1.0 (2026-10-07)

**New** — Introduced program status reporting via OSC 7501 for terminals and agent dashboards (see Program status: https://pi.dev/docs/latest/terminal-setup#program-status). Added Claude Haiku 5.5 (anthropic/claude-haiku-5-5) with adaptive thinking and prompt caching. Added +name and -name entries to --tools to change default tool selection (see Tools: https://pi.dev/docs/latest/cli#tools). Added OpenAI's GPT-6 Luna as a classifier model through the Decisions API and supported images in codemode's models.classify() (see Use classifier models: https://pi.dev/docs/latest/models#use-classifier-models). Added native llama.cpp decision models served by llama.cpp 0.6.0 or later (see Classification: https://pi.dev/docs/latest/llama-cpp#classification). Added aborted to agent sessions and durationMs to tool render contexts (#10549, #10607: https://github.com/earendil-works/pi/issues/10549, https://github.com/earendil-works/pi/issues/10607).

**Changed** — Changed outputPad to also apply to ! command output, tool output, and summary blocks (#9946, #10557 by @rwachtler: https://github.com/earendil-works/pi/issues/9946, https://github.com/earendil-works/pi/pull/10557). Changed pi mcp login --timeout to limit the whole sign-in procedure instead of only the browser wait (#10565: https://github.com/earendil-works/pi/issues/10565).

**Fixed** — Fixed bash and PowerShell results losing Took after reloading a session and ensured execution times are properly recorded (#10549: https://github.com/earendil-works/pi/issues/10549). Fixed managed installs keeping every old release so pi update now keeps only the new release and the previous one (#10392, #10511 by @davidbrai: https://github.com/earendil-works/pi/issues/10392, https://github.com/earendil-works/pi/pull/10511).

## Upgrade notes

This release brings powerful model additions and terminal monitoring capabilities. Upgrading to v1.1.0 is highly recommended for all users to enjoy improved stability and new features.
