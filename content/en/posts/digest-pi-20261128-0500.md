## Versions overview

Pi 1.7.0 has been released, introducing terminal session resume support via OSC 7577, expanded image generation capabilities in codemode, and prompt cache optimizations for GitHub Copilot. This release also updates default model mappings across several providers and completely removes install telemetry.

## Version by version

### Pi 1.7.0 (2026-11-27)

**New** — Added session resume capabilities via the Program Resume Protocol (OSC 7577), allowing compatible terminals to restore active sessions with original flags (`--tools`, `--no-extensions`, `-e`, `--skill`, `--system-prompt`) after restarts (see [Terminal setup](https://docs.pi.dev/latest/terminal-setup#program-resume) and [Program Resume Protocol](https://www.superlogical.com/rex/docs/build/program-resume)). Added the `--agent-dir <dir>` command line flag for `PI_CODING_AGENT_DIR`. Codemode now supports Radius image generation and accepts an optional `{ aspectRatio, size }` third argument in `models.generateImages()` (see [Codemode](https://docs.pi.dev/latest/codemode#generate-images)). GitHub Copilot prompt caching is preserved when changing thinking levels or tools on supported Claude 5.x and GPT-6 models (see [Settings](https://docs.pi.dev/latest/settings#model-and-thinking)).

**Changed** — Cloudflare Workers AI and AI Gateway now default to `@cf/zai-org/glm-5.3`. Updated `ant-ling` default model to `Ling-3.1-flash` (`thinkingFormat: "ant-ling"` remains as a deprecated alias for "deepseek", thanks to @lvisei in [#11800](https://github.com/earendil-works/pi/pull/11800) and [PR author](https://github.com/lvisei)). Replaced retired `qwen4-max-preview` with `qwen4-max` on Qwen Token Plan Individual. Copilot Claude and GPT-5.3 Codex / MAI-Code now properly retain caches or handle mid-conversation system messages (see [#12316](https://github.com/earendil-works/pi/issues/12316)).

**Fixed** — Fixed an issue in `/llama "Download model"` where typing an `owner/repository` pattern and navigating with arrow keys downloaded typed text instead of the highlighted search item (see [#12465](https://github.com/earendil-works/pi/issues/12465)). Corrected key hints in the extension editor and session rename dialogs to properly reference `tui.input.submit`.

**Breaking** — Removed install telemetry reporting (`/api/report-install`), the `enableInstallTelemetry` setting (`SettingsManager.getEnableInstallTelemetry()` / `setEnableInstallTelemetry()`), and the `PI_TELEMETRY` environment variable. Ensure any scripts or configurations relying on these telemetry settings are removed upon upgrade.

## Upgrade notes

Upgrading to Pi 1.7.0 is recommended for all users. Users with custom scripts managing telemetry settings should remove telemetry references before upgrading, and terminal users can take advantage of the new session resume protocol on supported terminal emulators.
