## Versions overview

This update covers Pi v1.4.0, focusing on expanding model capabilities, improving terminal compatibility, and optimizing summary and concurrency mechanisms.

## Version by version

### Pi 1.4.0 (2026-10-21)

**New** — Introduced image input support for classifiers where codemode models.classify() accepts images for TypeSafe's Jev and Cloudflare's Clef models across typesafe, cloudflare-workers-ai, and OpenRouter. Added a Models Configuration reference generated from the models.json schema (see https://github.com/earendil-works/pi/issues/10790). Compaction and branch summaries now use the model's output limit instead of a fixed output cap (see https://pi.dev/docs/latest/compaction#compaction). Codemode now waits for a free worker, queuing parallel scripts and in-process subagents instead of failing, with limits managed via PI_CODEMODE_MAX_WORKERS (see https://pi.dev/docs/latest/codemode#limits). Added support for the Rex terminal including OSC 8 hyperlinks, truecolor, and inline images.

**Changed** — Provider attribution headers now come from pi-ai's client identity, and extensions' before_provider_headers handlers no longer see OpenRouter, NVIDIA NIM, and OpenCode attribution headers. generateSummary() and generateSummaryWithUsage() now ignore their reserveTokens parameter. Changed the default GitHub Copilot model from gpt-5.4 to gpt-6.1-sol. Changed the default NVIDIA model to nvidia/nemotron-3.5-super-vl-120b-a12b (see https://github.com/earendil-works/pi/pull/10910). Changed the default Xiaomi model to mimo-v2.6-pro. Grok 4.3 and Grok 4.5 on xai now offer the xhigh thinking level. ChatGPT Business usage-limit errors are no longer retried.

**Fixed** — Fixed compaction and branch summaries failing with "generation hit the token cap" when reasoning used most of the fixed summary output limit (see https://github.com/earendil-works/pi/issues/9512 https://github.com/earendil-works/pi/issues/9075). Fixed models.schema.json missing descriptions for provider and model fields (see https://github.com/earendil-works/pi/issues/10790).

## Upgrade notes

This version delivers enhanced model and terminal capabilities alongside refined summary generation. Upgrading to v1.4.0 is recommended while keeping an eye on default model changes.
