## Versions overview

Pi 1.6.0 is a major update introducing GPT-6.2 Astra and GPT-6.2 Sol models across OpenAI, Azure, and Codex providers, with GPT-6.2 Sol set as the new default. This release also brings breaking changes to the extension rendering API, updates Qwen Token Plan provider integrations, and includes security updates and bug fixes.

## Version by version

### Pi 1.6.0 (2026-11-20)

**New**

- Added GPT-6.2 Astra and GPT-6.2 Sol to openai, azure, and openai-codex providers, setting GPT-6.2 Sol as default (see [Providers](https://docs.pi.dev/latest/providers)). Thinking level off is unavailable as reasoning effort none/minimal are rejected. Azure provides 1.05M context; Codex serves Sol with 500K and Astra with 272K.
- Added `qwen4-max-preview` to Qwen Token Plan Individual providers ([#12259](https://github.com/earendil-works/pi/issues/12259)).
- Added `deepseek-v4.1-flash` and `deepseek-v4.1-flash-1017` to Qwen Token Plan Individual providers, along with per-plan API key variables ([#11773](https://github.com/earendil-works/pi/issues/11773)).
- Added transcript notices when OpenAI drops reasoning items after context compaction on GPT-6.2.

**Changed**

- Updated Qwen Token Plan providers to use current gateways and renamed them to "Qwen Token Plan Team" and "Qwen Token Plan Team CN" ([#11773](https://github.com/earendil-works/pi/issues/11773)).
- Updated `undici` to 8.12.4 to address multiple security advisories ([#12200](https://github.com/earendil-works/pi/issues/12200)).
- Set `gpt-6.2-sol` as the default model for openai, azure, and openai-codex providers at the same price.
- Adjusted `find` tool path patterns to be relative to the search directory ([#12066](https://github.com/earendil-works/pi/issues/12066)).
- Changed `llama.cpp` extension default connection port to 9931 ([#12001](https://github.com/earendil-works/pi/pull/12001) by [@julien-c](https://github.com/julien-c)).
- Enabled Anthropic message threads by default for providers with `baseUrl` on `api.anthropic.com` ([#11987](https://github.com/earendil-works/pi/issues/11987)).
- Moved the session resume command to its own line for easier triple-click selection ([#12237](https://github.com/earendil-works/pi/issues/12237)).

**Fixed**

- Fixed an issue where `read` stored a stale note about image unsupport, which replayed after switching to a vision model ([#12131](https://github.com/earendil-works/pi/issues/12131)).

**Breaking**

- Extension components: `render()` now returns `readonly string[]`, and `Container` returns the same cached array while children remain unchanged. Extensions modifying render output in place must copy it first ([#9549](https://github.com/earendil-works/pi/issues/9549)).

## Upgrade notes

Upgrading to Pi 1.6.0 is recommended to access the new GPT-6.2 models and security fixes. Extension developers should review their `render()` implementations to ensure compliance with `readonly string[]` return values.
