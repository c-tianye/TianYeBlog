## Versions overview

This release covers Pi version 1.0.4. It introduces enhanced CLI tool pattern matching, MCP execution control, image persistence in Codemode, and bug fixes across prompt rules, connection retries, and session management.

## Version by version

### Pi 1.0.4 (2026-10-05)

**New** —

- Added `*` pattern matching support to `--tools` and `--exclude-tools` (for example `--tools read,codemode,'mcp__radius__*'`), and added `--no-mcp` to disable built-in MCP support for a single run; `--tools` now keeps MCP tools unless an entry starts with `mcp__` (see [Tools](https://pi.dev/docs/latest/cli#tools) and [MCP tools](https://pi.dev/docs/latest/cli#mcp-tools)).
- Codemode image persistence: `tools.read()` on image files now resolves to an image block that `image()` can display (see [Call tools](https://pi.dev/docs/latest/codemode#call-tools)).

**Fixed** —

- Fixed syntax highlighting losing colors after the first line of multiline strings and comments in fenced code blocks ([#10143](https://github.com/earendil-works/pi/issues/10143)).
- Fixed Codemode scripts not receiving images from `read`: `tools.read()` now resolves to an image block for image files ([#10251](https://github.com/earendil-works/pi/issues/10251)).
- Fixed MCP OAuth sign-in failing with `invalid_redirect_uri` on servers with OpenID Connect client registration such as `mcp.modem.dev`; pi now registers as a native client ([#10493](https://github.com/earendil-works/pi/issues/10493)).
- Fixed `--tools` removing MCP tools which left `pi --tools codemode` without any MCP servers; `--tools` now keeps MCP tools unless an entry starts with `mcp__`.
- Fixed MCP session shutdown returning while a server was still connecting ([#10249](https://github.com/earendil-works/pi/issues/10249)).
- Fixed system prompt rules and skills hint naming tools hidden by `prepareLoadout` ([#10343](https://github.com/earendil-works/pi/issues/10343)).
- Fixed Bedrock requests failing with "The pending stream has been canceled" after a stalled HTTP/2 connection not being retried automatically ([#10379](https://github.com/earendil-works/pi/issues/10379)).
- Fixed Codemode scripts patching built-ins (e.g. `Array.prototype.toJSON = ...`) crashing pi and leaving the tool call unsettled by freezing built-ins before the script runs ([#10444](https://github.com/earendil-works/pi/issues/10444)).

## Upgrade notes

Upgrading to version 1.0.4 is recommended for all users relying on Codemode image workflows, tool filtering, and MCP integrations.
