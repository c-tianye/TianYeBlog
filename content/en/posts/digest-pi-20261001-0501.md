## Versions overview

This release brings Pi v0.99.2, focusing on optimizing MCP server exposure and authentication, Anthropic workload identity federation, and various tool and session stability improvements.

## Version by version

### Pi v0.99.2 (2026-09-30)

**New** — Added MCP server descriptions, new authentication options (oauth.clientName and auth.provider), Anthropic workload identity federation (see https://pi.dev/docs/latest/providers), and /reload support for newly added tools. Check out tool exposure at https://pi.dev/docs/latest/mcp#control-tool-exposure and OAuth authentication at https://pi.dev/docs/latest/mcp#authenticate-with-oauth.

**Changed** — MCP servers with default codemode exposure no longer appear in the codemode description and connect in the background without blocking the first prompt, see #10212 (https://github.com/earendil-works/pi/issues/10212).

**Fixed** — Fixed new sessions intermittently ignoring the saved default model or warning that no models are available (#9962, #10190 by @davidbrai, see https://github.com/earendil-works/pi/issues/9962 https://github.com/earendil-works/pi/pull/10190 https://github.com/davidbrai).

## Upgrade notes

Upgrading to v0.99.2 is recommended for a smoother background MCP loading experience and enhanced authentication configurations.
