## Versions overview

This release introduces Pi version 1.0.1, bringing Nix flake support, project-level MCP server configurations, Cloudflare Clef classifiers, and a series of security fixes and experience improvements.

## Version by version

### Pi v1.0.1 (2026-10-03)

**New** — Added a Nix flake for macOS and Linux (nix run github:earendil-works/pi/stable and nix profile add github:earendil-works/pi/stable, see https://pi.dev/docs/latest/quickstart#1-install-pi and https://github.com/earendil-works/pi/pull/9137); project overrides for user-level MCP servers via .pi/mcp.json and /mcp (see https://pi.dev/docs/latest/mcp#configure-servers and https://github.com/earendil-works/pi/issues/10277); OAuth Client ID Metadata Documents (CIMD) support via oauth.clientRegistration: "cimd" (see https://pi.dev/docs/latest/mcp#authenticate-with-oauth and https://github.com/earendil-works/pi/issues/10302); tool renderers for any tool via pi.registerToolRenderer() (see https://pi.dev/docs/latest/extensions#tool-rendering and https://github.com/earendil-works/pi/issues/10285); Cloudflare Clef and Clef Flash classifier models (see https://pi.dev/docs/latest/models#use-classifier-models, https://github.com/earendil-works/pi/pull/10316, and https://github.com/earendil-works/pi/pull/10322); added a copy key (app.message.copy, default ctrl+x) to OAuth sign-in screens.

**Changed** — pi update on global npm installations now recommends migrating to the managed installation from the pi.dev installer; Anthropic tools added or redefined mid-conversation are now defined inline to preserve prompt cache.

**Fixed** — Fixed vulnerable brace-expansion by pinning 5.0.12 as a direct dependency (GHSA-q2hr-2g5m-vwhr etc., https://github.com/earendil-works/pi/issues/10288); fixed a trailing comma in --models adding an extra model (https://github.com/earendil-works/pi/issues/10334); fixed a codemode script printing in a loop crashing pi by running out of memory (https://github.com/earendil-works/pi/issues/10283); fixed JPEG, GIF, and WebP images rendered by extensions not appearing in Kitty, Ghostty, WezTerm, and Warp (https://github.com/earendil-works/pi/issues/10292).

## Upgrade notes

This release includes crucial security fixes and powerful feature enhancements. Users are strongly recommended to upgrade. Global npm users may consider migrating to the managed installation method.
