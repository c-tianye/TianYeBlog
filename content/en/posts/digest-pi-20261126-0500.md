## Versions overview

This release covers Pi v1.6.1, focusing on decision model integration, granular configuration splitting, enhanced extension capabilities, and critical stability fixes.

## Version by version

### Pi v1.6.1 (2026-11-25)

**New** — Added decision models in codemode including GitHub Copilot's gpt-6-luna-decisions and Radius decision models (see https://docs.pi.dev/latest/codemode#classify); added individual settings under Notices in /settings for cache misses, cache warming, compaction costs, and reasoning drops (see https://docs.pi.dev/latest/settings#model-and-thinking); added blockedKind option for extension UI dialogs (see https://docs.pi.dev/latest/extensions#program-status-kind). Added compat.supportsStrictMode for Google models (#12321 https://github.com/earendil-works/pi/issues/12321); added full_output_error to bash tool structured output (#10585 https://github.com/earendil-works/pi/issues/10585); added gpt-6-luna-decisions model for GitHub Copilot (#12395 https://github.com/earendil-works/pi/issues/12395) and responseId to codemode classify results.

**Changed** — Changed the default Mistral model from devstral-medium-latest to mistral-medium-latest; updated after_provider_response to fire for HTTP error responses and retried attempts (#12376 https://github.com/earendil-works/pi/issues/12376); updated first-time setup to show colored pi logo and only ask about analytics.

**Fixed** — Fixed selecting the xhigh thinking level for Gemini 4 Hydrogen and Neon failing with mapping errors (#12184 https://github.com/earendil-works/pi/issues/12184); fixed sessions with very many entries failing to load with call stack size exceeded (#12154 https://github.com/earendil-works/pi/issues/12154).

**Breaking** — Replaced showCacheMissNotices setting with individual notices.* configurations and removed SettingsManager.getShowCacheMissNotices() and setShowCacheMissNotices().

## Upgrade notes

Upgrading is recommended to leverage new decision models and improved error handling. Please note the breaking changes regarding transcript notice settings when updating custom integrations.
