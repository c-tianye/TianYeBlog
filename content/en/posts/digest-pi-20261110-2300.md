## Versions overview

This release contains Pi 1.5.2, focusing heavily on session management improvements and enhanced handling of missing working directories.

## Version by version

### Pi 1.5.2 (2026-11-10)

**New** — Fork sessions whose folder is gone: when a session's original folder was moved or deleted, you can now fork it into the current folder instead of only continuing, so later resumes no longer ask. See [Continue or switch sessions](https://pi.dev/docs/latest/sessions#continue-or-switch-sessions).

**Changed** — When a session's working directory no longer exists, for example after the project folder was renamed, interactive mode now offers Continue, Fork, or Cancel instead of only continuing. Continue runs the session in the current directory without storing the choice, as before; Fork copies it into the current directory as a new session with a new ID, like --fork, so the next resume no longer asks.

**Fixed** — Fixed /import of a session whose working directory no longer exists leaving a copy in the session directory, and continuing it leaving a second copy with the same ID (s.jsonl and s-1.jsonl); the failed copy is now removed (#11975 by @petrroll, fixes #11060). See links: https://github.com/earendil-works/pi/pull/11975 https://github.com/petrroll https://github.com/earendil-works/pi/issues/11060. Fixed Anthropic OAuth requests reporting an outdated Claude Code version.

## Upgrade notes

Upgrading is recommended to benefit from better error recovery when working directories are moved or renamed.
